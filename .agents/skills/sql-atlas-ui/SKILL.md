# Interface workflow

Prioritize the SQL editor and actionable diagnostics. Show the source location for each finding and support keyboard navigation to it. State when schema, plan, or actual execution metrics are unavailable. Use compact labels and readable density; avoid implying precision from static heuristics. Verify light and dark themes, keyboard access, narrow layouts, and error states in a running browser. Do not display inactive features as operational controls.
