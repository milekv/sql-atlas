# Community conduct

Keep technical discussions respectful and focused on evidence. Welcome questions from new contributors; critique code and claims rather than people. Harassment, discrimination, threats and publishing another person's private data are not acceptable.

Report a problem privately to the repository maintainer through the GitHub profile or, for security issues, the route in [SECURITY.md](SECURITY.md). Maintainers may remove abusive content and restrict participation. When reporting, include links and context so the issue can be reviewed fairly.
